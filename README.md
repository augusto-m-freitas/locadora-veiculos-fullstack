# 🚗 Full-Stack Car Rental System (Sistema de Locadora)

Este projeto Full-Stack foi desenvolvido como simulação de um sistema de gerenciamento de locadora de veículos. A aplicação abrange desde a construção de uma API RESTful robusta até a interface de usuário, demonstrando o ciclo completo de desenvolvimento de software e integração de sistemas.

## 🛠️ Tecnologias e Arquitetura

**Back-end (API):**
* **C# / .NET 8.0:** Desenvolvimento da lógica de negócios e endpoints.
* **ASP.NET Core Web API:** Estruturação das rotas HTTP.
* **Entity Framework Core:** ORM utilizado para modelagem do banco de dados (Code-First) e Migrations.

**Front-end:**
* **HTML5 & CSS3:** Estruturação da interface utilizando modais, abas e formulários.
* **JavaScript (Vanilla):** Lógica de interface e manipulação do DOM.
* **Fetch API:** Consumo assíncrono dos endpoints disponibilizados pelo back-end.

## ⚙️ Principais Funcionalidades

* **CRUD Completo:** Criação, leitura, atualização e exclusão aplicadas a 5 entidades essenciais do negócio.
* **Filtros e Pesquisas Avançadas:** Funcionalidades de busca customizada, processando parâmetros enviados do front-end para consultas eficientes no banco de dados via API.
* **Renderização Dinâmica:** Atualização da interface (tabelas e modais) em tempo real baseada nas respostas JSON da API, sem recarregar a página.
